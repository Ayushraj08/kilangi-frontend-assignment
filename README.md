# Kilangi – Luxury Jewellery Homepage  
**Frontend Assignment Submission**

---

## 📌 Project Overview

**Kilangi** is a modern, luxury jewellery homepage designed and developed as part of a frontend assignment.  
The objective was to translate high-fidelity design references into a **clean, responsive, accessible, and production-ready webpage** using **core web technologies**.

This project demonstrates my ability to:
- Build pixel-accurate layouts
- Maintain scalable CSS architecture
- Handle responsive design thoughtfully
- Write clean, readable, and maintainable code
- Focus on real-world UX instead of dummy implementations

---

## 🛠️ Tech Stack

- **HTML5** – Semantic, accessible structure
- **CSS3** – Modular architecture using:
  - Design tokens
  - Layout CSS
  - Component-based styles
  - Responsive breakpoints
- **JavaScript (Vanilla)** – Minimal, purposeful interactions
- **Google Fonts** – Playfair Display & Inter
- **Git & GitHub** – Version control and submission

> No frameworks were used intentionally to showcase strong fundamentals.
